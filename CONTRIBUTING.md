# Contributing / 贡献指南

Thank you for improving Multi AI Roundtable.

1. Create a dedicated branch and keep each change focused.
2. Run `npm ci`, `npm run typecheck`, `npm run test:werewolf`,
   `npm run test:clocktower`, and `npm run build`.
3. Preserve existing functionality: AI Chat, AI Roundtable and Expert Team
   have priority over newly added modes.
4. Never submit cookies, session data, live-account screenshots, tokens,
   browser profiles, generated debug traces, or real private conversations.
5. Changes to provider selectors should document the affected website version.
6. Game-rule changes must include deterministic tests for hidden information,
   action validation, interruption/resumption and replay.
7. Mark changed files clearly and preserve copyright and attribution notices
   according to the applicable license.

**Third-party rights:** Do not submit third-party game text, copyrighted role descriptions, proprietary
assets or unauthorized source code. AI Fog Council uses its own original rules.
