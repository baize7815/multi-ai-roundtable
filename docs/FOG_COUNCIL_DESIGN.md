# AI 迷雾议会：原创模式设计与公开发行迁移方案

项目作者：[@baize7815](https://github.com/baize7815)。本文件为独立游戏系统的原创设计基线。

## 目标与隔离边界

在原有 Chrome 扩展内提供一个新的多 AI 隐藏信息议事游戏。只复用 Provider 页面适配、专用窗口、Final-only 完成监听、持久化、重复动作防护与侧栏基础 UI，不复用旧第五模式的 Trouble Brewing 剧本、角色名称、能力、阵营数量机制、公开投票处决、昼夜流程或胜负条件。

第一阶段将新规则以完全独立的 src/game/fog-council/ 模块落地、通过 mock tests。原第五模式留在本地，现有 AI 对话、圆桌、专家团、狼人杀不做任何功能修改。第二阶段再把 UI/存储迁移到全新 fog_council id，并移除所有公开发行包中旧第五模式的内容。

## 故事与目标

一座跨地域信号网络出现传输污染。六至八名匿名议员组成议会，必须在有限的五轮议事中识别每轮唯一正确的 A/B/C 维护频道。阵营不是通过杀死玩家取胜；玩家全程保有发言与投票资格。

清晰阵营：五轮内累计三次选对维护频道即成功修复网络。
迷雾阵营：五轮内累计三次选错频道即成功扰乱网络。若全票平局无法确定维护频道，算作一次迷雾胜利。第五轮结束必然产生胜者。

六至八人均有两名迷雾成员，其余为清晰成员。双方都可以在公开辩论中质疑他人线索，但没有夜杀、处决、死者票、提名、毒杀、替身死亡、僧侣防护、恶魔转移等旧第五模式的核心机制。

## 原创身份牌及私密信号

| 身份 | 阵营 | 每轮私有信号 |
| --- | --- | --- |
| 定标师 | 清晰 | 获得精确的正确频道 |
| 双轨师 | 清晰 | 获得包含正确频道的两个候选 |
| 排误师 | 清晰 | 获得一个肯定错误的频道 |
| 巡波师 | 清晰 | 获得一个约 75% 可靠的观测频道，提示始终固定，不显示本轮是否准确 |
| 协调师 | 清晰 | 奇数轮获两个候选，偶数轮获精确频道 |
| 守线员 | 清晰 | 获得频道分类信息（B 或 A/C） |
| 雾织者 | 迷雾 | 获得真实频道，可在公开发言中故意误导 |
| 噪讯师 | 迷雾 | 获得真实频道，可在公开发言中故意误导 |

每局用固定种子分配身份与轮次频道，任何初始座位排列都只使用上述八种原创身份，不复用原游戏角色 ID 和角色序列。信号由引擎掌管，AI 只选择发言与表决，不能自称主持人篡改真相。

## 五轮有限状态机

briefing（本轮线索私发） → debate（全部议员顺序发言） → ballot（密封表决，顺序执行 Provider，但未结束前不公开票型） → reveal（公布唯一正确频道、票型合计及本轮得分）→ 下一轮 briefing 或 ended。

每个阶段和动作附 gameId、round、phaseId、operationId。动作提交只允许当前阶段的玩家；一个座位每轮仅可成功提交一次发言和一次表决。相同 operationId 重放必须幂等，其他重复票被拒绝。

## 隐私规则

public 事件给所有人，seat 私密事件只给对应玩家。其他玩家无法通过 prompt、侧栏、导出或者后台发送链路获取未公开的真实频道、密封投票、私有信号及其他身份。

议员发言一律作为不可信文本进行转义与引用，不能通过伪造机器动作或系统分隔符改变裁判规则。游戏 Provider 仅提交最终答案；允许显示非私密进度提示但不直播思考。
