# Multi AI Roundtable v0.2.2

本版基于已公开的 `v0.2.1-local-classic` 分支，更新 Chrome 扩展至 **v0.2.2**，不合并到 `main`。

## 新增：AI 对话独立预设

- 在「设置 → AI 对话」中为各模型选择独立的预设，默认「无预设」。
- 复用专家团现有预设库和导入、导出功能；两种模式的预设选择相互独立。
- 新对话首次发送时保存预设快照；每个模型仅在该会话首次回复时注入一次，后续追问不重复注入。
- 预设文字不写入侧栏展示的用户消息；更改设置不影响已有会话。
- 未选择预设或旧会话保持原始发送行为。

这里的「系统提示词」通过 AI 网页普通输入框发送，并不具备厂商 API 中 system 角色的优先级。

## 兼容与限制

保留多模型对话、AI 圆桌、专家团、狼人杀和 v0.2.1-local-classic 已公开的经典第五模式。用户须自行登录对应 AI 网页，网页改版、验证码或配额变化可能影响适配。

此前经典第五模式涉及第三方规则的独立版权判断，本次未获得或声明任何额外授权。完整游戏引擎自动模拟及实际 Chrome 视觉检查仍缺少完整验收，不能宣称所有场景验证通过。

## 安装

下载 `Multi-AI-Roundtable-v0.2.2.zip`，解压，在 `chrome://extensions/` 开启开发者模式，选择「加载已解压的扩展程序」，定位到压缩包中的 `dist/` 文件夹。

## 验证

- `npm run typecheck`：类型检查
- `npm run test:werewolf`：AI 对话、专家预设、圆桌和狼人杀回归测试
- `node scripts/test-clocktower-core.mjs`：第五模式核心测试
- `npm run build`：生产构建
