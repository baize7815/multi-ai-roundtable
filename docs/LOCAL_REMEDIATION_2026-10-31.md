# 本地整改执行记录（2026-10-31）

> 依据：项目根目录《multi_ai_roundtable_报告.md》（评审对象 v0.2.0）；执行对象：当前本地 v0.2.3 / local/classic-mode-restoration。
> 本文记录整改执行阶段的状态；后续按用户授权推进提交与 GitHub 分支同步，版本信息见 [v0.2.4 更新说明](RELEASE_NOTES_v0.2.4.md)。

## 执行计划与结果

### 阶段一：阻塞和稳定性（P1）
- [x] 解耦回复完成判定和前台加速开关，加长停止生成确认静默窗口，防止过早截断；后台帧泵增加有界连续脉冲。
- [x] 对流式增量消息限频持久化，侧栏使用轻量事件增量更新、避免整体消息区域反复重建。
- [x] 图片及附件 Base64 拆分为持久化侧车存储，只在实际派发前恢复；加入 unlimitedStorage 权限、过期孤儿侧车回收、独立测试。
- [x] QA 模式增加完整并发中断入口，清除所有 pendingOperations 并取消对应 Provider 请求。
- [x] 核查第五模式：当前代码已经更名为 clocktower，已有格式修复、暂停和恢复机制；未将旧版 fog-council 锚定解析器移植过来。

### 阶段二：交互与状态机（P2）
- [x] 顶栏导航改为自适应胶囊与激活标签，调整最窄侧栏布局和第五模式图标。
- [x] 圆桌 Prompt 增加首轮/当前轮/最后一轮、参与阵容与最后收敛；重建/关闭标签时检查绑定并恢复专家与 QA 预设初始化状态。
- [x] 狼人杀女巫药物目标合法性；删除狼人杀或迷雾议会对局后回收绑定标签页；人类投票先出现、AI 仍单路串行。
- [x] 附件能力预检，能力不足的模型提示并仅发送文字，避免全局出错。
- [x] 回复策略改为「后台脉冲（默认）/智能唤醒/前台轮播」，只有主动选择轮播才自动切页。
- [ ] 私密游戏窗口的系统级原生遮挡问题尚未得到真实 Chrome/Windows 跨窗口测试；不使用无法保证运行且可能额外耗电的无声 WebAudio 绕过技巧。

### 阶段三：功能和体验（P3/P4）
- [x] 新用户获得 6 个专家模板；现有用户可手动补充，不覆盖已有预设；专家团空白会话可快捷选预设。
- [x] 轮数拖动只在 change 时写入持久化；移除侧栏中与现行后台调度重复的旧串行执行代码。
- [x] 回收超过 7 天且不再被会话/队列引用的独立附件对象。
- [x] 增加「汇总结论」模型选择与后台排队操作；圆桌异常回合增加重试 / 跳过控制。
- [x] ?standalone=1 中 QA 使用宽屏多列卡片，系统深色偏好适配主要界面。
- [ ] 狼人杀与迷雾议会的全屏双栏棋盘/时间轴尚未完成浏览器实机验收。
