# Multi AI Roundtable v0.2.3

基于 `local/classic-mode-restoration` 发行分支，不合并 `main`。本版本包含 v0.2.2 之后完成的本地功能修复与新增能力。

## AI 对话：预设及时生效

- 修复在已经聊过的 AI 对话中选择预设后，后续发送仍没有附加提示词的问题。
- 当前选定的预设在下一次发送时生效；每个模型的同一预设只注入一次。
- 切换预设或修改其内容后重新注入；清除预设选择后不再附加指令。
- 用户消息仍保持原始内容，且原有聊天历史不会被改写。

**注意：** 模型仍可能记住同一网页聊天中先前发送的指令；要彻底清除先前上下文，应新建 AI 网页会话。本扩展注入的是普通网页消息中的指令，不是官方 API 的 system 角色。

## AI 对话：网页标签体验

- AI 对话标签页不再加入 `AI Dialogue` 分组，已有对话绑定的受管标签尝试解除分组。
- 开启「回复加速」时优先切换到正在生成回复的模型，多模型同时生成时轮流展示。
- 只选一个模型时，自动展示该网页并在回复结束后继续停留。
- 手动切换标签会暂停本轮自动跟随；圆桌、专家团及游戏的既有标签管理仍予保留。

## 新增：七牛云专家预设备份

- 在「预设管理」新增手动云端上传、下载并合并、下载并替换，本地 JSON 导入导出继续可用。
- AI 对话与专家团共用预设库。备份仅含预设名称和提示词，不包含对话历史、登录状态和模型绑定。
- 固定 S3 对象：`multi-ai-roundtable/experts.json`，与 PromptSave 的备份路径隔离。
- 下载合并按名称匹配；下载替换前要求确认，优先保留同名预设 ID 及相关模型配置。
- 对接用户自配的七牛 S3 HTTPS 地址，使用 AWS Signature V4，JSON 上下行限制 5 MiB。
- 端点及 AccessKey 本机保存；SecretKey 只保存至浏览器会话。**浏览器中的长期密钥仍然存在安全风险**；请配置私有存储桶和尽可能小的权限，公开部署更推荐服务端短期凭证。
- 扩展主机权限新增 `https://*.qiniucs.com/*`，实际上传下载端点限制为七牛 S3 域名。

## 验证与限制

- `npm run typecheck`：静态类型检查。
- `npm run test:werewolf`：既有模式、预设修复、标签切换、云端签名与模拟 GET/PUT 回归。
- `node scripts/test-clocktower-core.mjs`：第五模式核心测试。
- `npm run build`：生产构建。

七牛云**仅通过模拟请求、独立签名计算和 JSON 导入测试**；尚未在真实存储桶验证 API 权限、网络、CORS 或真实上传下载。Chrome 真实窗口交互及经典第五模式完整自动模拟也未完成正式验收。

## 安装

下载 `Multi-AI-Roundtable-v0.2.3.zip` 并解压，在 `chrome://extensions/` 开启开发者模式，选择「加载已解压的扩展程序」并指向 `dist/` 文件夹。发行包同时提供 SHA256 校验文件。
